# Media Outlet

## This project will collect data from RSS feeds to analyse their content and provide insights into media coverage trends.

#### This project contains three folders: `pipeline`, `dashboard`, and `terraform`

- `pipeline`: Handles the extraction, transformation, and loading (ETL) of data from various media outlets into a DynamoDB database.
- `dashboard`: Provides a visual representation of the collected data using Streamlit.
- `terraform`: Contains infrastructure as code for setting up the necessary cloud resources.
